Autoevaluación y nivelación

Lista de autoevaluación para el estudiante

El docente convierte cada conocimiento previo en una pregunta de sí/no para que el estudiante se autoevalúe antes de iniciar el curso.

¿Puedo crear una clase en Java con sus atributos, métodos y constructor?
¿Entiendo la diferencia entre clase y objeto, y puedo dar un ejemplo?
¿Sé qué es la herencia y cuándo usarla?
¿Puedo escribir una consulta SQL con JOIN entre dos tablas?
¿Tengo configurado Git en mi computador y sé hacer commit + push?
