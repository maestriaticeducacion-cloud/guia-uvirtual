Lo que necesitas para acceder y participar exitosamente en los cursos virtuales UVirtual

Cómo leer este documento

Mínimo (Min)

Configuración mínima para que el curso funcione. Permite navegación, lectura y entrega de actividades básicas.

Recomendado (Rec)

Configuración óptima para una experiencia fluida: videoconferencias, laboratorios virtuales, edición de medios.
